# Matrix portrait catalogue

Pre-generated portrait avatars for the "Create" tab of the avatar window
(modules/ui/avatar-studio.mjs). Files are named `<gender>-<age>-<glasses>.jpg`
with gender in {f,h}, age in {jeune,adulte,senior}, glasses in {lunettes,sans}.

Provenance: AI-generated images (OpenAI image model, prompted by narmod,
2026-07-31), 192x192 JPEG. Missing combinations are declared as `null` in
AVM_CAT and shown as "to generate" in the UI.

Note: usage of AI-generated artwork in the official web client is pending
final confirmation by the PokerTH development team (sp0ck).
