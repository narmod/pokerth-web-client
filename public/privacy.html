Web Client — Privacy

Last updated: September 10, 2026

Who runs this

The PokerTH Web Client is a free and open-source hobby project, maintained by an individual — Arnaud Obscur (“narmod”) — in collaboration with the PokerTH project. It is not a company and has no commercial purpose: no ads, no sale of data, no advertising profiling, no third-party trackers.

What stays in your browser

Your settings, statistics, achievements and logs are stored in your browser. They leave your device only in the cases listed below. You can clear them from your browser settings or with Restore defaults.

What this server receives

  • Visit statistics. A random identifier created by your browser counts distinct devices and visits. The server stores only a hashed form of it, never with a name or an IP address. Daily figures are deleted after about 13 months; the hashed identifiers used to tell new from returning devices are kept longer. Browser, operating system and language are only counted as totals.
  • Settings sync (registered accounts). When you log in with a registered pokerth.net account, your settings (the config.xml shared with the desktop client, plus web options such as theme, seats, shortcuts, language, avatar choice and ignore list) are stored on this server under your account name, so they follow you to other devices. On by default; it can be turned off in Advanced options.
  • Error reports. When a script error occurs, the error message, page, client version, browser user agent and a shortened IP address are sent to the server admin to fix bugs. They are kept in memory only and erased when the server restarts. On by default; it can be turned off in Advanced options.
  • Polls and music votes. If you answer a poll or rate a track, your answer is stored with the hashed identifier so that each device counts once. Track plays are counted without any identifier.
  • Leaderboard. If you play on a LAN or private server through this client, your nickname, avatar choice and game statistics are stored for the leaderboard. Resetting your statistics removes the entry.
  • Technical connection data. Your IP address is needed to deliver and protect the service and may appear in the server logs for security (rate limiting, blocking abusive connections). It is used for nothing else.

Third-party services

When you connect to pokerth.net (or any other game server), you are using a service operated independently of this web client, with its own rules. This page only covers the web client and the server that hosts it.

Translation. When you tap the translate button (🌐) on a chat message or a forum post, the text is sent from your browser to Google Translate, or to MyMemory if that fails, or finally through this server to Google. Nothing is sent unless you tap, and the feature can be turned off in Advanced options.

Radios. When you play a radio station in the music player, your browser connects directly to that station.

Log analysis. If you use Analyse log file, the .pdb file is sent through this server to the pokerth.net log analysis service.

Your rights & contact

Under the GDPR you may request access to, correction of, or deletion of data concerning you (for example synced settings or a leaderboard entry). Please contact the pokerth.net administrators, whose details are on the pokerth.net Imprint page.

For questions about the web client itself, you can also open an issue on GitHub.
