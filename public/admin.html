Login form

Default entry screen for new visitors, plus (for LAN / dedicated) which server to connect to. The mode applies on a first visit only. LAN server sets the default server fields, never a lock: Automatic uses the page's own address (port 7234, no TLS), Forced uses the host, port and TLS set below. In both cases a player can edit the fields and the server they last connected to is remembered, so only players who never picked one of their own follow a change made here. With Forced, the proxy auto-follows the host and is rebuilt on every reconnect, so the client always reconnects. A forced proxy URL (ws:// or wss://) is pushed to every client and locks the field; hiding the field removes it and its label from the login form. All of this applies to the LAN / dedicated mode only — the Internet (pokerth.net) mode is never affected.

Search engine visibility (SEO)

Off by default. When off, every page is served with noindex, nofollow and robots.txt blocks all crawlers — a self-hosted install stays out of Google and AI search engines. Turn it on only for a public instance you want indexed: the page then gains a description, Open Graph / Twitter cards, a canonical link, structured data (JSON-LD) and a crawler-readable summary, and robots.txt, sitemap.xml and llms.txt are generated from the public URL below. Applies immediately (no restart needed).

Roll back a deployment

        
Every state this server has actually served, newest first. Rolling back checks the chosen commit out again — the quickest way out when a deploy breaks the client. Static swaps the served files with no dropped connection; with restart also reinstalls dependencies and restarts, which is what a change to proxy.js needs. The state you are on now is recorded first, so you can always come back forward.
