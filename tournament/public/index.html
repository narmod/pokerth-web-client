Tournament director beta

Sit & Go tournaments on the LAN servers of this install: the director opens the table for the registered players, follows the game to the end and seals a signed result.

Organizer sign-in

For now, the admin master token. Keys limited to one server come later.

LAN only. Create the tournament and add the players. Then either let the director open the table on the LAN server (invitations, seat check, hand-over to the first player, result recorded by itself), or set the result yourself — typed in, taken from a Table check, or from a PokerTH log. Every action goes into the tournament’s sealed journal; the validated result is signed.
